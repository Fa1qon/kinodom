# Сборка и тесты

## Что нужно

- Windows 10 или 11 (x64).
- Go 1.26. Зависимости Go лежат в `vendor/`, поэтому для сборки сервера сеть не нужна.
- Для установщика — Inno Setup 6 (`winget install JRSoftware.InnoSetup`).
- Для приложения Android:
  - JDK 17 и Android SDK с платформой 36;
  - переменные `JAVA_HOME` и `ANDROID_HOME` (их можно задать и для пользователя).
- Node.js — только для тестов пульта.
- ffmpeg для своего плеера уже собран и лежит в `third_party/ffmpeg`. Пересобрать его можно в Docker Desktop, команда — в [third_party/ffmpeg/README.md](third_party/ffmpeg/README.md).

## Сборка

```powershell
.\build.ps1              # bin\kinodom.exe и bin\kinodomw.exe; есть JDK и Android SDK — ещё bin\kinodom.apk
.\build.ps1 -Installer   # и установщик dist\Kinodom-<версия>-setup.exe
```

- `build.ps1` кладёт рядом с программой `ffmpeg.exe` и `ffprobe.exe` из `third_party/ffmpeg`. Без них плеер в браузере выключен, а «Смотреть» открывает внешний плеер.
- `kinodomw.exe` — та же программа без консоли. Ею Windows открывает ссылки `kinodom://` (плеер, «Разрешить доступ») и значок в трее.
- Приложение Android подписывается ключом из `%USERPROFILE%\.kinodom`. Ключ создаёт `android\make-key.ps1` при первой сборке.
- Сохраните эту папку: без того же ключа новую версию приложения не поставить поверх старой.

## Тесты

```powershell
.\test.ps1   # go vet, gofmt, тесты Go, тесты пульта (Node), тесты приложения (JVM)
```

- Тесты пульта — в `web/web_test.go`, это сценарии Node над ES-модулями из `web/static`. Без Node они пропускаются.
- Тесты в сеть не ходят: трекеры, Кинопоиск и источники каналов в них — фейковые серверы на `httptest`.

## Версии и выпуск

- Номер версии — в файле `VERSION`.
  - `build.ps1` берёт его и метку git.
  - Сборка с коммита с тегом `v<VERSION>` без правок — чистый номер: `0.14.0`.
  - Между выпусками к номеру добавляется метка: `0.14.0-3-g1a2b3c4` — 3 коммита после тега; `-dirty` — несохранённые правки.
  - Номер видно в `kinodom version`, в установщике и в «Состоянии».
- Номер сборки приложения Android — `1000 + число коммитов`: Android ставит обновление, только если номер больше.
- Выпуск:
  1. Поднять `VERSION`.
  2. Перенести пункты из «Не выпущено» в новый раздел `CHANGELOG.md`.
  3. Поставить тег `vX.Y.Z` на этот коммит.
  4. Собрать `.\build.ps1 -Installer`.
  5. Приложить установщик к выпуску на GitHub.

## Команды программы

`kinodom` без аргументов печатает список. Главные команды:

| Команда | Что делает |
|---|---|
| `run` | сервер в консоли (для разработки) |
| `install` / `uninstall` | служба Windows (от администратора); `uninstall --purge` — ещё настройки и скачанное |
| `check` | проверка установки: служба, пульт, брандмауэр, ссылки `kinodom://` |
| `grant [--write] ПАПКА` | права службы на папку |
| `source`, `meta`, `torrent`, `catalog` | проверка трекеров, Кинопоиска, движка и каталога вживую, без сервера |
| `version` | версия |

## Тестовый сервер рядом с установленным

Тестовый сервер не трогает установленную службу, если запустить его так:
- своя папка данных — переменная `KINODOM_HOME`;
- свой порт — `kinodom.json` в этой папке: `{"apiPort": 8097, "torrentPort": 42097}`.

```powershell
$env:KINODOM_HOME = "$env:TEMP\kd-home"
.\bin\kinodom.exe run --downloads "$env:TEMP\kd-dl"
```
