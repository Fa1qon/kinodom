# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), номера — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

Версия 0.14.0 — ждёт проверки установщика.

### Каталог
- Rutracker: страница раздачи разбирается и при новой разметке без блока magnet — хэш из запасных мест, иначе из списка раздела.
- Порядок разделов Rutor и Rutracker: раздающие, качающие, новые, число скачиваний (Rutracker со входом); переключатель над разделом, выбор запоминается, умолчание — в «Параметрах → Каталог».
- Новая вкладка «Кинопоиск»: популярные фильмы и сериалы (русские и зарубежные) и документальные; порядок — популярность, оценка Кинопоиска, оценка IMDb, новизна; карточка ведёт в поиск раздач.
- Формат в приоритете подсвечен везде: карточка, поиск, «Другие раздачи», страница раздачи, «Загрузки».
- На странице раздачи сериала крупно видно, какой сезон и какие серии скачаются.
- Постеры: оригинал вместо миниатюры imgbox, заглушки хостингов не считаются постером.

### Загрузки и медиатека
- Скачанное идёт в папки «Фильмы» и «Сериалы» медиатеки, если они заданы; срок хранения действует и там.
- Скачанное в папках медиатеки не появляется второй раз своим файлом.
- «Удалить» на карточке медиатеки: свой файл — с диска (с подтверждением), скачанное — как в «Загрузках».
- «Разрешить доступ» к папке медиатеки даёт и право изменения.

### Каналы
- «Смотреть» у любого источника и у нераспознанного потока — видео прямо в пульте, с размером кадра, временем до картинки, подвисаниями и текущей передачей.
- «Кадры» — миниатюры всех источников канала, «нет картинки» у неработающих.
- «Новый канал» из «Не распознано» — название, логотип (адрес или файл), категория, страна; «Удалить канал» в его настройках возвращает потоки в «Не распознано».

### Пульт
- «История» — между «Загрузками» и «Настройками».

### Документация
- README — для пользователя; сборка — в BUILD.md, устройство кода — в DEVELOPMENT.md.

## [0.13.0] — 2026-10-01

Первая публичная версия.

### Сервер
- Служба Windows с модулями под сторожем: торренты, каталог, Кинопоиск, IPTV, медиатека, обнаружение в сети.
- Каталог Rutor и Rutracker (вход, разделы), поиск через Jacred или Jackett, постеры и рейтинг Кинопоиска, подписка на сериалы.
- Торрент-движок с просмотром во время загрузки, очередь, удаление недокачанного, контроль места.
- IPTV: плейлисты, проверка источников, версии каналов по часовым поясам, телепрограмма, избранное.
- Медиатека: папки с фильмами и сериалами.
- Обнаружение сервера в домашней сети (SSDP) и раздача приложения для Android (`/app`).

### Пульт
- Веб-пульт для ТВ (стрелки пульта), телефона и ПК: каталог, загрузки, каналы, медиатека, история, настройки.
- «Настройки → Приложение» — только в приложении: встроенный или системный плеер каналов, обновление приложения.

### Приложение для Android
- ТВ и телефон, Android 7.0+: поиск сервера в сети или ввод адреса, пульт во весь экран.
- Встроенный плеер каналов на Media3: листание по списку, набор номера, список с передачами, плашка «Сейчас/Дальше», источники по очереди.
- Обновление с сервера: проверка при каждом входе, «Обновить» в пульте.

### Установщик
- Inno Setup: служба, правила брандмауэра, приложение для Android внутри.
